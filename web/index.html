Reads Base Profile, Adaptive Profile, Q# and PyQIR output and OpenQASM 2 and 3. diff checks the compiled program against the original at -O0, branch by branch. The state vector is limited to 20 qubits here. Wider programs still run: Clifford programs on a stabilizer tableau up to 5,000 qubits, permutation and phase gates such as adders on a bit vector at any width, Clifford circuits with a few T gates as a sum of stabilizer states, and anything else as a matrix product state that reports any truncation. line5.cal is a five qubit device with gate, readout and T1 and T2 errors. Drop a .ll or .qasm file on the editor to open it. Source on GitHub.
